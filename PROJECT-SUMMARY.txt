═══════════════════════════════════════════════════════════════════════════════════
🚨 LIMITACIONES Y NOTAS IMPORTANTES
═══════════════════════════════════════════════════════════════════════════════════

ESTA ES UNA VERSIÓN PROTOTIPO:

1. ⚠️ SIN BACKEND REAL
   └─ Los datos se guardan solo en localStorage
   └─ Se pierden al limpiar caché del navegador
   └─ No se sincronizan entre navegadores/dispositivos
   └─ Máximo 5-10MB de almacenamiento

2. ⚠️ SIN AUTENTICACIÓN REAL
   └─ Contraseña en texto plano (NO usar en producción)
   └─ Sin JWT o tokens reales
   └─ Sin MFA (autenticación multi-factor)
   └─ Accesible directamente desde DevTools

3. ⚠️ SIN ENCRIPTACIÓN
   └─ Datos no encriptados
   └─ Sin HTTPS
   └─ Sin protección de datos sensibles
   └─ RGPD no implementado

4. ⚠️ ALMACENAMIENTO LIMITADO
   └─ localStorage = 5-10MB máximo
   └─ No escala para producción
   └─ No hay backups automáticos
   └─ Pérdida de datos al limpiar datos del navegador

5. ⚠️ RENDIMIENTO
   └─ Sin optimización de imágenes
   └─ Sin caché avanzado
   └─ Sin CDN
   └─ Sin compresión de assets (en desarrollo)

🆘 SOLUCIONAR PROBLEMAS
═══════════════════════════════════════════════════════════════════════════════════

PROBLEMA: No puedo abrir el archivo
SOLUCIÓN: 
- Verifica la ruta: c:\Users\vspc\Desktop\TFG\WebNovaManager-CMS\admin\index.html
- Intenta con un servidor local: python -m http.server 8000

PROBLEMA: No se guardan los datos
SOLUCIÓN:
- Verifica que localStorage no esté deshabilitado
- Abre DevTools (F12) > Application > Local Storage
- Busca claves que empiezan con "webnova_"

PROBLEMA: Pierdo datos al cerrar navegador
SOLUCIÓN:
- Es normal en prototipo (localStorage se limpia con caché)
- Usa "Guardar datos locales" antes de limpiar caché
- En v1.5 usaremos backend para persistencia real

PROBLEMA: El diseño se ve roto en móvil
SOLUCIÓN:
- Asegúrate de que viewport está correctamente configurado
- F12 > Toggle device toolbar (Ctrl+Shift+M)
- Prueba con diferentes resoluciones
