# Cambios del prototipo

## Estado actual

WebNova Manager funciona como prototipo CMS para TFG:

- Login de desarrollo estable.
- Base de datos autocreable en XAMPP.
- Gestion de paginas con bloques.
- Widgets reutilizables con claves estandar.
- Render publico desde contenido guardado en MySQL.

## Pendientes recomendados

- Separar instalador/migraciones de la conexion normal a base de datos.
- Completar gestion real de usuarios.
- Anadir validaciones de seguridad adicionales para produccion.
- Documentar pruebas de accesibilidad, responsive y seguridad.
